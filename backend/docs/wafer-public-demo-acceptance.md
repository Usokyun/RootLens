## 几何事实怎样改变结论

| 已保存的作用域 | 失效 die／有效 die | 密度 |
| --- | ---: | ---: |
| 全片有效区 | 986／1,139 | 0.865672 |
| 中心区 | 156／172 | 0.906977 |
| 中间区 | 433／516 | 0.839147 |
| 边缘区 | 397／451 | 0.880266 |

分类器输出 `nearfull`。同时，全片、中心和边缘的密度通过各自阈值，最大八邻域失效连通分量覆盖 985／986 个失效 die（0.998986 ≥ 0.70）。这五个条件与异常前置门控属于同一张晶圆的联合签名。边缘虽高密度，`edge_ring` 的中心低密度条件与分类条件均不成立；它不入榜。

统一引擎唯一支持近全片失效图案；分数 `−0.3928571429`（总代价 `0.25 + 1/7`，不是概率），有 6 条保存路径、12 条唯一源边。每条边按图中真实方向逐段核对，可从中心区观测连到保存条件、来源断言和原始网格范围。

从保存路径定位观测时，右侧网格只高亮对应 `spatial_zone` 的有效 die；四区实屏计数与上表逐项相等。截图 `13-wafer-center-actual-zone.png`、`13-wafer-edge-actual-zone.png` 对应中心和边缘实测。高亮是对保存原网格的只读投影，不重算推理；未附网格时不补画。

**属性消融。** 对同一已保存 Frame 的内存副本，仅把 `spatial.largest_component_ratio` 改成 `0.50`，保留分类器 `nearfull` 和所有密度。原执行版本无匹配；当前版本仍无完整支持、0 正式路径，只在「待验证」保留近全片线索。这验证了图实际使用连通性。它不是另一次真实网格测量，未写回发布 Frame 或原运行。阈值为本演示声明的启发式，不是产线判据；一个样本不能估计模型准确率。
