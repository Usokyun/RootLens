# MVTec 分级验收：形态可比，结构仍待测

已复核的 [公开演示包](../data/demo/graded_rca/mvtec/README.md) 把较大块状与细长响应作为两种可计算的形态。形态内解释共享观测，未强排工位原因。外轮廓缺口与表面／光路变化作为图上并列检查项，不入评分。

## 对照为什么没把结构加进评分

固定公开正常对照（`bottle/test/good/001.png`）和表面对照（`bottle/test/contamination/000.png`）同批用 CPU PatchCore 与真实 adapter，统一输入路径为 `test/unknown`，无标注、无 VLM。前者 detector `false`、分数 0.35247、无 ROI，结果 `no_match`（异常门关闭）；后者 `true`、分数 0.85101，ROI 面积 0.101929、长短比 1.075269、离心率 0.712547，**也**支持块状两解释（S=0.679525，并列）。这两条是本机真实模型→adapter→同一分级图验证，不是新增隔离服务 Raw 请求。Frame 与原对照 PNG 随包。

先固定阈值再比较。以三张正常参考定位圆心和尺度，外轮廓在三档亮度阈值都通过拟合／尺度／弧段质量，但固定 ROI 对应弧段的 006 Q90 内凹相对最接近对照只多 0.91–0.95% R，不到事先要求的 2% R。进一步用正常图的径向梯度定环带，在真实 mask 上名义差 26.21pp；半径 ±0.03R 扰动最小差 20.12pp，不到冻结的 25pp。两项均未进入测量目录或图规则。[叠图](../data/demo/graded_rca/mvtec/reference-outline-comparison.png)与[固定参数、参考 ID 及实测](../data/demo/graded_rca/mvtec/reference-checks.json)可直接检查。完整外轮廓不排除内部裂纹；复核应换光、多角度，并补同瓶前后工位证据。
