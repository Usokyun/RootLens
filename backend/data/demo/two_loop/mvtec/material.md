# 玻璃瓶局部异常：区域主轴偏心演示规则

这是一份 RootLens 自著的非商业演示资料。对象为 [MVTec AD](https://www.mvtec.com/research-teaching/datasets/mvtec-ad) 的 `bottle`。数据集用于检测异常，本演示的形态条件不是工厂标准，也不验证加工过程。仅使用 Bottle PatchCore 的单区域掩膜几何；不读取样本名、目录标签、标注或外部视觉语言模型结果。

## 形态：较大且不显著单轴拉伸的局部异常响应

以当前检测区域为关注对象（`$focus`）。以下三项必须在**同一主体和同一区域**全部成立：

1. 连通区域像素数占**检测网格**总像素数至少 **10%**（`geometry.area_ratio ≥ 0.10`，无量纲、单位 `1`）。
2. 区域轴对齐包围框的长边不超过短边的 **2 倍**（`geometry.aspect_ratio ≤ 2`，无量纲、单位 `1`）。
3. 区域像素坐标的主轴离心率不超过 **0.90**（`geometry.eccentricity ≤ 0.90`，无量纲、单位 `1`）。离心率从同一区域坐标的协方差得到；它补充包围框长短比，因为对角狭带也可具有近方形包围框。

以上三个圆整阈值均是**演示启发式**（`declared_demo_heuristic`），不是拟合值、检测器阈值或工厂标准。异常检测为真的前置门控不能代替三项几何条件。如果面积、长短比合格但离心率超界，就不支持这个特定形态；这不代表图像正常，也不自动支持另一种原因。缺测则不肯定该形态。

## 同一形态下的两个待排查解释

**本工位取放接触扰动**和**进入工位前已有局部表面损伤**都是待排查假设。二者均可能经同一个“局部表面反差改变”机理呈现上述形态，使用相同的预期强度；这组观测不区分二者。没有工位时序、接触证据或可验证部位信息，不能确认根因或认定瓶口。派生的粗形态标签和图像坐标都不作为额外条件。
