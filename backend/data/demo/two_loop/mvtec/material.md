# 玻璃瓶局部异常：几何证据演示规则

这是一份由 RootLens 项目自著的非商业演示资料。输入对象是 [MVTec AD](https://www.mvtec.com/research-teaching/datasets/mvtec-ad) 的 `bottle`；该数据集用于异常检测，不提供这里两种工艺解释的验证。检测使用 Bottle PatchCore；只读同一检测区域的掩膜几何，不要求外部视觉语言模型。不得用图片名称、目录标签或标注作为推理输入。

## 一个可核验的现象

现象名称：**较大且不细长的局部异常响应**。以当前检测区域为关注对象（`$focus`），同时满足两项条件才构成本演示现象：

- 连通区域像素数占**检测网格**总像素数至少 **10%**（`geometry.area_ratio ≥ 0.10`，无量纲，单位 `1`）。
- 该区域轴对齐包围框的长边不超过短边的 **2 倍**（`geometry.aspect_ratio ≤ 2`，无量纲，单位 `1`）。

两个圆整阈值是作者明确声明的**演示启发式**（`declared_demo_heuristic`），不是数据集标签、模型校准值或工厂质检标准。异常检测结果为真的前置门控不能代替这两个同区域的几何条件。任一测量缺失就不能仅凭异常检测肯定该现象。

## 两种待排查解释

将以下两种**假设**并列，均可经“局部表面反差改变”解释上述响应，使用相同的预期强度：

1. **本工位取放接触扰动**：本工位接触可能引入局部表面扰动。
2. **进入工位前已有局部表面损伤**：已有表面损伤可能在检查时呈现相似响应。

两个候选共享同一机理和同一现象；这两项掩膜几何不区分它们。没有工位时序或接触观测，不能确定工艺根因；也不能凭图像坐标认定瓶口或其他具体部位。
