# 人工图谱修订：同窗替代分支与正常参考标度

这份 RootLens 自著记录用于编辑和审计，不是文本模型的输出。只用固定版本的独立 [`d00.dat`](https://raw.githubusercontent.com/camaramm/tennessee-eastman-profBraatz/0643318858ce7c87292bd59820b459e12a13d009/d00.dat) 估计参照尺度，不以验证序列或文件标签定阈。

## 保留关系，纠正替代语义

两种反应器响应是同一机理的替代表现：异常门下，XMV10 上移，且 XMEAS21 出口变暖 **或** XMEAS9 仍在近参考区。保留文本构图生成的两个签名和实际源边，添加一个引用两签名的 OR 现象，替换两条同时要求的 `expected` 为一条 `expected`。补偿成立时，不另扣未出现的暖出口。冷凝侧 XMV11、XMEAS22、XMEAS11 为独立同窗联合分支。反应器、冷凝侧各两假设仍未被本测量区分。

## 连续曲线和预算

从 `d00` 的 500 × 52 正常矩阵拟合每通道均值与样本尺度（`ddof=1`），在五个不重叠 100 点窗上读取有符号 `mean_z` 和窗口内 `std_z`（`ddof=0`）。XMV11、XMEAS22 的 `|mean_z|` 最大分别为 **0.1775、0.1505**；XMEAS11 的 `std_z` 约为 **0.7266–1.1670**。这些同一参照内的正常窗不是独立校准总体，不提供工业假阳率。

| 量和方向 | 支持起点 → 饱和 | 反证起点 → 饱和 |
| --- | --- | --- |
| XMV10、XMEAS21 有符号均值上移 | +2 → +3 | −0.25 → −1.75 |
| XMEAS9 近参考，两个界共享一槽 | 从 −2/+2 向区间内 1.0 达饱和 | 从 −2/+2 向区间外 1.0 达饱和 |
| XMV11、XMEAS22 有符号均值上移 | +0.5 → +2 | −0.25 → −1.75 |
| XMEAS11 窗口波动增大 | 1.5 → 3.0 | 0.7 → 0.0 |

正常窗只约束中性范围的选择；表内端点、宽度仍是 `declared_demo_heuristic`，不是原程序规格。反方向偏移与没有明显上移是不同证据。分级比较的六个唯一槽在一个同源 `window` 组，各占 1/6；缺项不重分权重。反应器由 XMV10 锚定；冷凝侧的调节、出口及分离器波动三项都作为判别锚点。锚点未测或不符不升为「有支持」，但两个不同槽仍有支持时可待核验。原异常门是硬前置，权重为零。
