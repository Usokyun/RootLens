# RootLens 可讲述 Demo 重构（2026-11-11）

## 目标与验收

依据 `RootLens_ChinaVis_2026 (2).pdf` §4–5，保留 backend-first 边界。
演示主线：异构观察 → 统一证据 → 知识关联与候选解释 → 来源核验 → 人工审阅与知识草稿。
不是复刻论文，不增加说明性首页，不用虚构来源或热力图填充页面。

## 保留与安全

开发分支 `codex/demo-narrative-redesign`。切分支前已有改动清单和 diff 留在 Git 忽略的
`.rootlens-cache/demo-redesign/`。不覆盖已有 UI/API 改动，不重导入数据库，不操作来源备份。
原图/模型热力图不可用时显示缺失；若使用受控合成 fixture，必须明示其性质、响应计算方式、
与真实数据集/训练模型输出的区别。所有推理结果仍为候选解释，不代表已验证工厂根因。

## 开发顺序

1. 壳层、可读名称、证据浏览与视觉产物契约。
2. 关联分析、来源核验、目标明确的审阅与知识草稿编辑。
3. 知识维护收敛、可复现演示资产、测试与真实浏览器验收。
