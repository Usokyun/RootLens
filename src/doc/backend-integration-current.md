# RootLens 当前集成边界

RootLens 是单一后端工作台：Vue 负责三页与交互，Python (`backend/src/kgtracevis/`) 负责素材解析、LLM 构图、Backbone／adapter、类型化 Evidence 和推理。Neo4j 保存隔离工作图，Postgres 保存素材、规范图登记、任务和分析快照。浏览器只展示收到的图和结果，不执行构图、推理或补造缺失媒体。

## 两条闭环及页面职责

| 页面 | 当前合同 |
| --- | --- |
| `/materials` 素材与构图 | 上传文件、登记 URL，或从唯一公开清单添加演示材料。异步提取显示实际片段和位置；LLM 制作、校验、编译、保存各有实际任务阶段。只选同场景和共享素材，新图默认待启用。素材移出保留文件、片段与历史引用，活动任务使用时禁止移出。 |
| `/graphs` 根因与图谱 | 从登记目录打开精确的 `graph_id`，用有向图查看节点、边、条件、绑定和来源。编辑规范知识，而非从画布投影反编译。支持完整 `rootlens-working-graph.v2` 导入、编辑和导出；导入创建新 ID，保存同图保留备份，明确启用后才可供新分析。 |
| `/evidence` 运行与证据 | 新建真实任务或选演示案例，打开保存分析 `/evidence/runs/:runId`。同一 Frame 查看输入、Backbone、Evidence、推理和图谱。候选贡献可以定位到实际观测、保存源边和相应媒体；切换窗口不串选择。 |

LLM 初稿声明可执行规则与证据绑定；工作图声明评分预算、判别锚点及可选数值曲线。新的制作任务提供确定性的初始比较预算，可在完整包中调整；LLM 不决定曲线宽度或相容权重。当前公共解释器为 **分级解释溯因**（默认，三场景共用）与 **RootKGD 图传播**（TEP 可选）。分级引擎比较规则允许的联合分支，对去重观测用固定预算计算 `支持−反证`，另报覆盖；RootKGD 用 52 维残差贡献比较图传播结构。两种分数不同义。

## 输入、演示和保存结果

- **原始输入**：MVTec 图像用对应对象模型（公开 Bottle 演示不调用 VLM）；TEP 序列带独立正常参考、52 通道和一基闭窗口；WM811K 接收 0/1/2 原生网格，原生类别不进分类器。缺模型或参考时明确失败。
- **Evidence 输入**：上传原生 `rootlens-evidence.v2`（单帧、数组或 `{frames:[…]}`）；读取原值、单位、主体、窗口／空间范围和参考。缺媒体不阻止推理；不会按 Frame 的任意路径取文件。详情导出本次原生 Frame，同图同解释器可复算。
- **公开演示**：`backend/data/demo/graded_rca/manifest.json` 是唯一白名单，含 MVTec 006、TEP d04/d05、WM811K 248536/31707。读取目录不写数据库；用户明确安装时按完整知识精确匹配并安装／启用配套图，不覆盖已有知识。手选图不被样例悄悄替换。模型和原始大数据按需本机准备。
- **保存结果**：保存当次的原始输入、Evidence、图快照、实际分支、候选和源边。修改登记图不会重算历史；分析中的源边和贡献来自该次快照。分级贡献路径不是布尔完整证明，相容分也不是根因概率。

浏览器内置 Demo、旧 Session/runtime 回放、旧 Run 档案、v1 图包、旧 Evidence 兼容入口及旧统一条件推理的公开路由已退役。受管演示跑真实后端任务；已有数据库、历史记录和本机运行文件没有被清除。旧资产和操作见退役前提交 `809fb8d`，不是当前客户端入口。独立研究代码和实验基线仍归 `backend/`。

## 运行与数据边界

- 日常使用本仓 `backend/.venv/`。首次安装、新空库初始化和启动步骤见[根 README](../../README.md#首次安装)。`npm run dev:all` 只启动前端和 API；不会初始化数据库。
- **只给新空库**执行 `npm run backend:init`。先等 Postgres 与 Neo4j 健康，初始化后再检查应用表。不要为了启动覆盖现有数据库、种子、卷或来源备份。
- `backend:db:*` 仅管理本机已预置的 `backend/runs/local_runtime/`，不下载、不建库、不导入种子、不管理 Compose 或其它服务。
- 环境变量优先于后端 `.env.local`、`.env`、YAML 和默认值。自定义端口同时调整 API 和 Vite 代理；连接凭据留在后端私有配置。项目命令不是开机／登录自启配置。
- `backend/runs/`、模型、大型原始数据与凭据不入库；可交换的小图、原生 Frame、公开材料与种子随仓维护。源 KGTraceVis 的保留和迁移证据见[来源项目](source-projects.md)与[迁移记录](../../backend/docs/rootlens-monorepo-migration.md)。

当前使用见[演示手册](../../backend/docs/graded-rca-demo.md)，接口见[双闭环 API](rootlens-two-loop-backend-contract.md)。`module-1/2/3`、`frontend_handoff` 和日期化验收记录是设计历史，不覆盖当前合同。
