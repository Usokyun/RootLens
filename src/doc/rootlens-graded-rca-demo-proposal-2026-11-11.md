## 1. 现有评分有两个问题

[旧统一条件内核](../../backend/src/kgtracevis/core/unified_reasoner.py)先执行真假判断，完整联合条件才进入主榜；[待验证层](../../backend/src/kgtracevis/core/unified_tentative.py)保住了部分支持，但仍按条件真假计数。对冻结 Bottle 006 Frame 做只读单值核算：`0.899` 仍有两个主榜候选（各 `−0.25`）；`0.901`、`0.94`、`0.98` 都只剩待验证，且代价全是 `1.25`。三个值对「形状不显著单轴拉伸」的意义不同，旧公式分不出来。

另一方面，两个玻璃工艺假设共享同一组几何证据。即使数值评分更细，也不会产生「哪道工位造成的」信息。需要**另一种观测或一条可证伪的竞争分支**，而不是调权重选出一个答案。[冻结对照结果](../../backend/data/demo/graded_rca/stage-a-comparison.json)保留读数，旧图和 Frame 可在退役前的 `809fb8d` 取回。

## 3. 统一方法：硬约束内的分级溯因

### 算法主干：比较的是候选的联合解释

```text
Evidence + 工作图
  → 按对象和任务目标召回候选假设
  → 沿图谱机理展开每个候选的预期表现，得到规则允许的联合分支
  → 在同一测量范围内绑定观测，去掉已违反硬约束的分支
  → 对每个分支的唯一实测量记支持、反证和缺项
  → 选出每个候选最有依据的分支，按状态分组、组内用同一个 S 排序
  → 保存实际使用的观测、图边、贡献与尚待核验的条件
```

复用现有图召回、有限 AND/OR 分支展开和观测绑定；**改的是分支评价、选择目标和输出依据**。对候选 `h`，在范围有效且未违反硬约束的分支中，若有「有支持」分支就从中选 `S` 最高的一条，否则选分最高的「待核验」分支。没有足够实测诊断量就不推荐。两个分组的 `S` 定义相同，状态仍表明证据是否足够。多个同时要求的期望作为一个联合解释评分，不能为了加分丢掉其中的反证。比如候选甲的规则是 `(A AND B) OR (C AND D)`，只有 `A`、`C` 有实测支持时，两条分支都只有一项支持，不能拼出完整解释；如果候选乙的规则就是 `A AND C`，它才有这两项联合支持。

### 观测连续评分，缺测单列

每条数值规则有支持方向和物理量单位。用 `d` 表示沿支持方向的有符号距离：低值更支持时 `d=t−x`，高值更支持时 `d=x−t`；区间 `[L,U]` 用 `d=min(x−L,U−x)`，两边合为一个条件、只计一次。近零可声明中性带；越过中性带后，两侧分别逐渐增加支持和不符程度：

```text
p_i = clip(( d_i − neutral_support_i)  / support_width_i,  0, 1)
c_i = clip((-d_i − neutral_conflict_i) / conflict_width_i, 0, 1)
```

`p_i`、`c_i` 是观测与该条件的相容／不符程度。对 `expected`，实测明确不符才成为该解释的反证；对 `possible`，缺少这种表现不扣原因分，只显示这条可选解释分支没有获得对应支持。必要条件只给真正硬的限制，不把 `.90`、`+2` 这类演示阈值当物理禁区。已知离散值可以保持离散；开放外观候选没列出某词是未知。缺测、单位不符、正常参考不匹配不产生负分，单列并影响证据覆盖。

曲线的方向来自资料或测量定义；端点、宽度明确注明**工程规格、参考估计或演示启发式**。MVTec 可用固定掩膜提取的轻微阈值扰动估计形态数值稳定性；TEP 可用与评测分开的正常窗估计测量波动，`mean_z` 是窗口平均标准化值，不是显著性检验；晶圆先用预先选定的图案对照检验方向和扇区稳定性。参数先冻结再看结果，不能为 `d05` 或 `31707` 调到正好命中。

### 分数来自整条解释，不给图边任意加权

1. **召回候选，再筛范围。** 按绑定的对象类型和任务目标召回图内候选，沿显式机理边展开它的观测期待；没有可检查的诊断观测时标为未评估，不用通用图邻居猜原因。主体、单位、窗口／正常参考和空间绑定必须有效；异常门关时不推荐故障候选。必要条件被有效反证可排除；未测则不能升为「有支持」。同一个 AND 必须在对应范围内联合检查，不能拿不同 ROI 或不同窗口拼起来。
2. **固定比较预算。** 每个比较任务先冻结适用候选共享的诊断测量槽和权重。同一槽由特征、主体、范围、适用参考决定；一个量被多条规则或多条路径引用不加票。已有 `dependency_group` 给同源证据一个固定预算，再在组内分配权重。例如同一个掩膜的面积、长宽比和离心率共用一个预算；由它们派生的 `spot` 不再加分。晶圆分类和空间量同源于一个网格，不算两个独立样本。
3. **对分支记支持、反证、覆盖。** 用固定归一化权重 `w_i`，`P=Σ w_i p_i`，`C=Σ w_i c_i`，`S=P−C`。未测或未被解释的槽贡献为零，分母不随候选或缺项收缩。另给分支覆盖 `V=该分支可核验的声明槽权重 / 该分支声明槽权重`；不把未知当反证，也不让少检查条件的候选靠小分母拿高分。第一版不加对所有单原因候选相同的假设常数，不用先验打破并列。
4. **保留联合语义。** OR 只比较合法整支并记录实际选择，不从两个失败分支各摘一个条件来拼成功；同时要求的多个表现不能只挑最好的一条算。共享事实、机制和源边只算一次。首版推荐至少有两项不同诊断量实测支持的分支；只有门控不出候选。对这些分支，必要条件已证实、判别锚点有实测净支持且 `S>0` 时标「有支持」；否则标「待核验」并列出缺项或冲突，仍显示同一个 `S`。徽标不把软阈值变回淘汰线。解释相同的两个原因仍并列。

`S` 的用途是**同一次分析、同一候选层级**的排序；不能和另一场景、另一引擎的分数或根因发生概率横比。所画的路径是实际用到的观测 → 条件 → 现象 → 假设的投影；分数按整支的唯一测量贡献求出，不按路径跳数乘分。候选共用的那段可以折叠，明确标为共享证据。

### Bottle 006：同一离心率对照的预期计算

只比较已有几何组，三项各占 `1/3`；面积 `0.228439`、长宽比 `1.117284` 在例子的充分支持区。离心率按 `d=0.90−e`、两侧宽度 `0.08`、中性宽度 `0` 演示；参数供审核，不是产线标准。除第一行外均是单值对照／缺测，不是新的图像测量。

| 离心率 | 离心率贡献 `p−c` | 路径相容 `S` | 覆盖 `V` |
| --- | ---: | ---: | ---: |

| `0.899` | `+0.0125` | `0.6708` | `1` |

## 4. 三张图各加什么知识

### MVTec：区分形状、结构缺口与表面／成像变化

**材料。** [MVTec AD 原论文，§3](https://www.mvtec.com/fileadmin/Redaktion/mvtec.com/company/research/datasets/mvtec_ad.pdf)提供外观／结构异常与定位基准；[Bucher Emhart Glass 缺陷手册](https://www.emhartglass.com/sites/default/files/publications/2024-07/BEG_BR0060RevA-Defect_Guide-WEB.pdf)印刷页 32–35 列瓶口崩缺及多个可能工位，128–129 页描述瓶身／底部沉积；[Basler 玻璃瓶检测案例](https://www.baslerweb.com/en/use-cases/shear-edge-detection-glass-bottle-inspection/)说明轮廓背光和多角度对抑制反光、确认瓶口结构的作用。厂商案例不能把 006 直接归为某道工序。

**拟做的图。** 保留「块状响应」，增加「细长响应」作为形态竞争分支；再把「可见轮廓缺口」和「轮廓未见缺口但内部有表面／成像对比变化」放在结构层比较。前两条用现有同 ROI 的尺度和主轴形态，不给 `morphology`、图像质心 `location` 重复投票或当瓶口定位。真正区分结构与表面的增量只选一项：同类正常瓶图配准后，计算 ROI 附近的外轮廓偏差，保存偏差曲线／叠加图和参考 ID。若单视角轮廓或配准不可靠，结果是未知；可选 VLM 只给可见外观提示，不填部位、材料或原因。内部结构裂纹不一定改变外轮廓，轮廓正常不排除裂纹。

**预期路径。** `同 ROI 的三项几何 → 局部异常形态 → 轮廓偏差（如有）→ 缺口候选 → 可能的取放接触／已有损伤 → 查同瓶前后工位图或换光复拍`。挑一个公开表面对照和一个正常图，在冻结参数后核验；不把目录类别或人工像素标注送给推理器。轮廓不可靠时仍可演示几何与待测项，不发布虚构的缺口证据。

### TEP：拆开反应器供冷、冷凝侧与执行器候选

**材料。** [Downs 与 Vogel，1993，变量表和扰动表](https://users.abo.fi/khaggblo/RS/Downs.pdf)给设备、变量和已定义扰动；具体方向以 [Braatz 固定版闭环程序](https://raw.githubusercontent.com/camaramm/tennessee-eastman-profBraatz/0643318858ce7c87292bd59820b459e12a13d009/temain_mod.f)的实际赋值和 [原过程模型](https://github.com/camaramm/tennessee-eastman-profBraatz/blob/0643318858ce7c87292bd59820b459e12a13d009/teprob.f#L789-L805)为准。`CONTRL18/10` 构成反应器串级；`CONTRL11` 实际读 `XMEAS(17)`（汽提塔底物流量）调 `XMV(11)`，**不是**照抄反应器的「读出口温度」控制结构。过程模型也将命令 `XMV` 与真实阀位状态 `VPOS` 分开。

**拟做的图。** 反应器保留「调节上移且温度近参考／出口变暖」两支；冷凝侧有独立候选和可观测组合：冷凝器冷却调节 `XMV(11)`、其冷却水出口 `XMEAS(22)`、分离器温度 `XMEAS(11)` 的方向或波动。`XMEAS(17)` 作为控制回路上下文，不把下游量当入口温度。已归档的 `d05` 窗中 `XMV(11) mean_z=+1.403`、`XMEAS(22) mean_z=+1.804`、`XMEAS(11) std_z=7.045`；前两项都未到旧 `+2`，第三项则是可检查的额外线索。波动可以帮助区别响应形态，不能单凭它诊断阀卡滞。不同来源的供冷变化、热负荷与执行器问题分别连到需补的入口温度、流量、实际阀位等。未保存的信号作为检查项。

**预期路径。** `同窗、同 d00 参考：XMV(10) 上移 + XMEAS(9) 近参考 → 反应器补偿 → 供冷侧偏暖／过程侧放热并列 → 查入口温度或热负荷`。用 `d04` 三窗和 `d05` 已有负例对比；如加执行器路径，优先验证实际阀位可得性，缺时不强行隔离。RootKGD 继续用同 Frame 的 52 维贡献做独立结构对照，不和连续相容分做平均。

### WM811K：让几种空间形态竞争，再输出排查线索

**材料。** [Wu、Jang、Chen，2015，§III、图 2](https://outlook.stpi.niar.org.tw/pdfview/tdop/1601)用 Radon 投影、几何和全局／局部失效密度区别图案；[RadAI 模型卡](https://huggingface.co/radai-agent/radai-wm811k-defect-detection)用来约束模型标签含义；[Shibuya 等的实际晶圆工艺案例](https://www.jstage.jst.go.jp/article/jjspe/75/2/75_2_256/_article/-char/en)用相似监控片和共用设备记录来追工序。单张公开网格没有对应的完整履历，所以图案能排，制造原因只能给检查项。

**拟做的图。** 扩为「近全片、边缘环、中环、边缘局部」四个相互可比较的图案分支。近全片用三区都高和连通性；边缘环用外圈相对中心／中间更高，中环用中间相对中心／外圈更高。边缘局部与连续边缘环用新增的**可用扇区密度分布**区分；有效 die 不够则该分支待核验。全片密度是三区的汇总，不与三区密度重复计分；环带对比是原密度的派生量，在同一预算内用。分类器标签作有界辅证；标签与空间量冲突时并列显示，不用模型自评分盖住网格。

**预期路径。** `248536 中心 .907／中间 .839／边缘 .880 ＋最大失效连通占比 .999 → 三段均高且连成大片 → 近全片图案 → 建议查同批次、复测和设备履历`。另一公开对照 `31707` 的保存分类是 Edge-Ring，标注是 Donut；但现有径向值是 `.485/.236/.303`，单靠这三段也不能把它改判为 Donut。保留这条分歧，用扇区图或其他已实现的区分量检验，不按标注反推阈值。

## 5. 交付契约与实施顺序

### 图谱和 Evidence 分工

- **素材到图谱：** 每域用有定位的原资料和简短自著说明，LLM 产出「实体／设备／部位 → 假设、机理与备选现象 → 可观测条件与待补证据」。允许输入能力目录与正常参考定义，不给演示样本读数、文件名标签或答案。编译检查特征、单位、scope、比较方向、来源、是否重复计票。原资料的工程陈述、项目启发式阈值和下一步检查分开；仓库带自著材料、引用和可合法分发的小型派生资产，不搬整本厂家手册。
- **Evidence JSON：** 仍保存 `obs_id / feature_id / subject_id / scope_id / status / value`（数值内含单位）`/ reference_id / dependency_group / procedure_id / raw_refs` 等测量信息；不保存「应该给这个原因多少分」。新增量由对应 adapter 从原始数据测得，未测就标未知。图包为现有 `observable_definitions` 添加有限的 `grade` 参数，例如 `direction=lower, pivot=.90, widths=.08, unit=1, basis=declared_demo_heuristic`；保留现有 `all/any/at_least`、来源、别名及候选语义。
- **结果 JSON：** 保存实际分支、逐项 `obs_id` 与实测值、曲线参数、`p/c`、有效权重、未测原因、`P/C/S/V` 与图边／来源 ID。原始附件继续点得回去。现有三页不重做，推理页多显示一条分解条和每项正／负贡献，图谱页可检查曲线和来源；旧保存结果保持原样。
